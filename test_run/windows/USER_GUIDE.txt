BAYOUFINDS OPS SUITE v1.0 — USER GUIDE
=====================================

START HERE
----------
1) Extract the ZIP.
2) Double-click RUN_ME.cmd.
3) Select [14] SOX Audit Runner.
4) Review reports in the output folder.
