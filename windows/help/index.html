Common Issues

  • Execution policy blocked: run powershell -ExecutionPolicy Bypass -File run-windows.ps1
  • Missing AD module: install RSAT or run from a domain admin workstation.
  • No domain access: AD scripts require domain connectivity.
  • Insufficient permissions: run as Administrator or with delegated AD rights.
  • InfoSec restrictions: endpoint tools may block script execution or module access.
  • Missing prerequisites: verify PowerShell, RSAT, network access, and permissions.
